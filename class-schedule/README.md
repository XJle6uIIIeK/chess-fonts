# Расписание — Android MVP

Нативное Android-приложение для месячного PDF-расписания колледжа.

Что уже реализовано:
- выбор группы;
- импорт PDF;
- геометрический разбор табличного расписания с объединёнными лекционными ячейками;
- определение текущей и следующей пары по системному времени телефона;
- повторное уведомление за 10 минут с предметом, преподавателем, кабинетом, временем и номером пары;
- отдельный переключатель этого повторного уведомления;
- уведомление около 20:00 с расписанием на следующий день и указанием, к какой паре приходить;
- отдельный переключатель вечернего уведомления;
- пересоздание системных уведомлений после импорта, смены группы, перезагрузки и изменения времени/часового пояса;
- поддержка нестандартного времени события, если оно явно напечатано в PDF.

Сборка: GitHub Actions, debug APK.
